## 1. Project Overview & Cultural Vision (نظرة عامة على المشروع)

**دواك (Dawaak)** هي منصة صيدلية إلكترونية متطورة مصممة خصيصاً لتلبية احتياجات وسلوكيات المستهلك والمريض في جمهورية مصر العربية. يجمع المشروع بين دفء وموثوقية الصيدلي المجتمعي المصري المخلص ("صيدلية الحي / الأجزخانة")، وسرعة وكفاءة التجارة الإلكترونية الحديثة عبر الهواتف الذكية.

تم تطوير المنصة وفقاً لنموذج هندسي متكامل يضم **7 تخصصات متعاونة** (قائد الفريق التقني، مصمم واجهات المستخدم وتجربة المستخدم، مطوّر الواجهات الأمامية، مطوّر الخدمات الخلفية، خبير الصيدلة والدواء المصري، مهندس الأمان وضمان الجودة، ومبتكر الحلول الإبداعية).

### الركائز الأساسية للمشروع (Core Pillars):
- **تجربة عربية أصيلة أولاً (Arabic RTL-First)**: الواجهة مبنية باتجاه اليمين لليسار (`dir="rtl"`) كافتراضي رئيسي، مع إمكانية التبديل الفوري للإنجليزية (`dir="ltr"`).
- **تصميم مريح للعين (Calming Medical Design System)**: لوحة ألوان طبية معتمدة على الزمردي والتيل المريح للأعصاب (`#0F766E` / `#00A86B`)، مع دعم كامل للوضع الداكن (Dark Mode) عالي التباين المتوافق مع معايير إمكانية الوصول العالمية (WCAG AA).
- **طباعة مصممة للشاشات الطبية (Cairo Typography)**: اعتماد خط "Cairo" العربي مع مسافات رأسية محسوبة (`leading-relaxed` / `1.625`) لمنع تشويه علامات التشكيل وتداخل الحروف.
- **شفافية تامة في التسعير بالجنيه المصري (Transparent EGP Pricing)**: عرض الأسعار الرسمية لجميع الأدوية والمستلزمات، مع حساب دقيق للخصومات وقيمة التوفير بالجنيه المصري (ج.م).
- **أمان وسلامة طبية صارمة (100% Synthetic Medical Compliance)**: جميع المستحضرات التجريبية في المرحلة الأولى تستخدم مواد فعالة افتراضية (`is_synthetic: true`) لمنع أي تضليل دوائي، مع التزام تام بحماية البيانات الصحية وفقاً لقانون حماية البيانات الشخصية المصري (رقم 151 لسنة 2020).

## 4. Quick Start Guide (دليل التشغيل السريع للمطورين والعميل)

### المتطلبات الأساسية (Prerequisites):
- تثبيت بيئة **Node.js** بإصدار `18.0.0` أو أحدث.
- أداة حزم **npm** بإصدار `9.0.0` أو أحدث.

### أوامر التشغيل والتحقق (Execution Commands):

```powershell
# 1. الانتقال لمجلد المشروع
cd "c:\Desktop\صيدليه اونلاين"

# 2. تثبيت التبعيات (Dependencies)
npm install

# 3. تشغيل خادم التطوير المحلي (Development Server)
npm run dev
# التطبيق سيعمل فوراً على الرابط: http://localhost:3000

# 4. بناء نسخة الإنتاج المحسّنة (Production Build)
npm run build
# يتم توليد صفحات ثابتة وديناميكية مع كود خروج 0 (Zero Errors)

# 5. تشغيل خادم الإنتاج (Production Server)
npm run start
# تشغيل التطبيق بالنسخة المحسنة على: http://localhost:3000

# 6. تشغيل جناح الاختبارات الآلية (Automated Multi-Tier Tests)
npm test
# أو مباشرة: node tests/runner.js
# ينفذ 63 اختباراً آلياً بنسبة نجاح 100% وكود خروج 0

# 7. فحص جودة الكود والالتزام بالمعايير (Linting)
npm run lint
# فحص ESLint للتأكد من خلو المشروع تماماً من أي أخطاء أو تحذيرات
```

## 5. Step-by-Step UI Verification Guide (دليل التحقق التفاعلي للعميل والمقيّمين)

اتبع هذه الخطوات التفاعلية لفحص جميع مزايا المرحلة الأولى على الرابط: `http://localhost:3000`:

### 5.1 التحقق من الاتجاه الافتراضي العربي RTL والتبديل للإنجليزية LTR
1. افتح المتصفح على `http://localhost:3000`.
2. لاحظ أن الصفحة تفتح تلقائياً باتجاه عربي يمين-إلى-يسار (`dir="rtl"` و `lang="ar"` على وسم `<html>`).
3. اضغط على زر تحويل اللغة في أعلى شريط التنقل (`Header`) والذي يعرض أيقونة الكرة الأرضية 🌐 (`English`).
4. **النتيجة المتوقعة**:
   - يتحول اتجاه الموقع فوراً إلى يسار-إلى-يمين (`dir="ltr"` و `lang="en"`).
   - تنقلب مواضع القوائم والأيقونات والهوامش بمرونة كاملة بفضل استخدام خصائص Tailwind المنطقية.
   - يتغير رمز العملة ديناميكياً من `ج.م` إلى `EGP`.
   - اضغط مرة أخرى للعودة إلى العربية (`عربي`).

### 5.2 التحقق من الوضع الداكن (Dark Mode Toggle)
1. في شريط التنقل العلوي (`Header`)، اضغط على زر الوضع الداكن (أيقونة القمر 🌙 أو الشمس ☀️).
2. **النتيجة المتوقعة**:
   - تنعكس ألوان الخلفية فوراً من الرمادي الفاتح (`#F8FAFC`) إلى لوحة ليلية طبية عالية التباين (`#020617` و `#0F172A`).
   - تظل النصوص واضحة ومقروءة بنسبة تباين تفوق معايير WCAG AA (> 7:1).
   - يتم حفظ تفضيل المستخدم في المتصفح (`localStorage`) بحيث يستمر عند الانتقال بين الصفحات أو إعادة تحميلها.

### 5.3 فحص الصفحة الرئيسية (Homepage Verification - `/`)
1. **شريط التنبيه الطبي العلوي**: يظهر في قمة الموقع باللون الكهرماني/الأخضر لتأكيد بيئة المحاكاة التجريبية وحماية المريض.
2. **واجهة الثقة (Hero Banner)**: يبرز شعار العلامة مع الشعار المصري *"صيدليتك في جيبك.. دواك يوصل لحد بابك"* وبطاقات الثقة (توصيل فوري خلال 60 دقيقة، أدوية أصلية مضمونة، واستشارات صيدلانية 24/7).
3. **البحث باللهجة المصرية والبحث الصوتي التفاعلي ("دور باللي بتقوله")**:
   - جرب الضغط على شرائح الأعراض السريعة بالعامية المصرية: `صداع`، `سخونية`، `حموضة`، `مغص`، أو `فيتامين`. ستلاحظ تصفية المنتجات فوراً وعرض الأدوية المناسبة.
   - اضغط على زر الميكروفون 🎙️ في مربع البحث لفتح نافذة البحث الصوتي التجريبية المحاكية ("سامعينك.. اتكلم براحتك بالمصري")، واضغط على أي عبارة مثل *"عايز مسكن للصداع"* أو *"فوار للحموضة"* لمشاهدة نتائج البحث الفورية.
4. **تصفح الأقسام الطبية الثمانية (8 Categories)**:
   - اضغط على أي قسم: مسكنات وألم، صحة الجهاز التنفسي، الجهاز الهضمي، أدوية الأمراض المزمنة، العناية بالبشرة، صحة العيون والأذن، فيتامينات ومكملات، أو الإسعافات الأولية.
5. **بنر العروض الترويجية**: عرض وفر 20% على باقة المناعة مع زر انتقال مباشر.
6. **شبكة المنتجات المميّزة**: تعرض بطاقات أدوية مصنعة بنظام عمودين متجاوبين للهاتف، تبرز الاسم التجاري باللغتين، شريحة المادة الفعالة المصنعة، السعر بالجنيه المصري، وزر الإضافة السريعة للسلة.

### 5.4 فحص صفحة تفاصيل المنتج (Product Details Page - `/product/[id]`)
1. اضغط على أي منتج من الصفحة الرئيسية (مثلاً: `/product/prod-syn-001` - سينترافول إكسترا 500 مجم).
2. **الاسم التجاري المزدوج**: اسم الدواء بالعربية والإنجليزية مع اسم الشركة المصنعة المصرية (معامل فارما نايل مصر).
3. **شريحة المادة الفعالة الافتراضية**: وسم بارز بلون مميز يوضح التركيبة الدقيقة (`Syntho-Paracetamol 500mg + Caffeine 65mg`).
4. **السعر والتخفيض بالجنيه المصري**: يظهر السعر الحالي (32.00 ج.م) ومشطوباً عليه السعر السابق (38.50 ج.م) مع نسبة التوفير.
5. **القوائم المطوية الطبية (Accordions)**:
   - افتح قائمة **الجرعة وطريقة الاستخدام**: تظهر الجرعات الموصى بها للبالغين والأطفال.
   - افتح قائمة **التحذيرات وموانع الاستعمال**: تبرز تنبيهات واضحة لمرضى الضغط والكبد.
   - افتح قائمة **ظروف التخزين والحفظ**: توضح شروط الحفظ أقل من 25 درجة مئوية.
6. **ميزة كاشف البديل الذكي ("وفر مع المصري")**:
   - اضغط على الزر البارز **"وفر مع المصري - كاشف البديل الذكي"**.
   - تفتح نافذة مقارنة جنباً إلى جنب تعرض البديل المصري المطابق بنسبة 100% في المادة الفعالة والتركيز (أدول ماكس إكسترا بسعر 18.00 ج.م مقابل 32.00 ج.م)، موضحاً توفير بقيمة **14.00 ج.م**.
   - يمكنك الضغط على **"استبدل البديل وأضف للسلة ووفر 14 ج.م"** للتبديل الفوري داخل السلة بنقرة واحدة!
7. **عداد الكمية وسقف منع الاحتكار**:
   - جرب زيادة الكمية، ستلاحظ أن الحد الأقصى يقف تلقائياً عند **5 علب كحد أقصى** تنفيذاً لتعليمات منع الاحتكار.
8. **شريط الشراء الثابت (Sticky Purchase Bar)**: يثبت أسفل شاشة الهاتف لعرض السعر وزر الإضافة المباشرة للسلة لسهولة الوصول بإبهام اليد.

### 5.5 فحص صفحة سلة المشتريات (Cart Page - `/cart`)
1. انتقل إلى صفحة السلة عبر أيقونة السلة في شريط التنقل العلوي أو الشريط السفلي.
2. **قائمة المنتجات**: مراجعة الأدوية المضافة مع عدادات التعديل (+ / -) وزر الحذف وسعر كل عنصر.
3. **شريط التوصيل المجاني الديناميكي (Free Shipping Progress Bar)**:
   - حد التوصيل المجاني هو **300 جنيه مصري**.
   - إذا كان المجموع أقل من 300 ج.م، يضاف رسم توصيل رمزي قدره **25 ج.م**، مع شريط تقدم يوضح المتبقي بدقة (مثلاً: *"أضف منتجات بقيمة 120 ج.م للحصول على توصيل مجاني"*).
   - إذا وصل المجموع إلى 300 ج.م أو أكثر، يتحول التوصيل تلقائياً إلى **مجاني (0.00 ج.م)** مع شارة خضراء مبروكة.
4. **ميزة تنظيم مواعيد الدواء الذكي ("جدول مواعيد الدواء الذكي")**:
   - اضغط على زر **"جدول مواعيد الدواء الذكي"** في السلة.
   - تفتح نافذة ذكية تقرأ أدوية السلة الحالية وتقسمها آلياً إلى خانات يومية منظمة:
     * **الصباح 🌅 (مع وجبة الإفطار)**
     * **الظهيرة ☀️ (بعد وجبة الغداء)**
     * **المساء 🌙 (قبل النوم)**
   - توفر بطاقة جاهزة للمعاينة والطباعة لتعليقها على باب الثلاجة لتسهيل التزام المريض.
5. **نافذة إتمام الطلب والدفع المصرية (Simulated Checkout Drawer)**:
   - اضغط على **"متابعة إتمام الطلب"**.
   - تفتح نافذة دفع تدعم خيارات الدفع الأكثر شيوعاً في مصر:
     * **الدفع نقداً عند الاستلام كاش (Cash on Delivery)** — الخيار الافتراضي الأكثر ثقة للمريض المصري.
     * **التحويل عبر إنستاباي (InstaPay QR Code)** مع كود تحويل فوري.
     * **المحافظ الإلكترونية الذكية (فودافون كاش، أورنج، اتصالات، وي باي)**.
6. **سلة فارغة تفاعلية**: عند حذف كل العناصر، تعرض الصفحة شاشة فارغة ودودة تدعو لتصفح الأدوية.

## 6. Compliance, Privacy & Medical Safety (الامتثال، الخصوصية والسلامة الطبية)

1. **إلزامية المستحضرات الافتراضية (Strict Synthetic Active Ingredients)**:
   - تنفيذاً لميثاق الأمانة الطبية، لا تستخدم المنصة أية ادعاءات دوائية حقيقية غير معتمدة أو بيانات مخترعة لأدوية كيميائية خطيرة.
   - كل مستحضر في الكتالوج يحمل صراحة علم `is_synthetic: true` وموسوم باسم علمي افتراضي (مثل: `Syntho-Paracetamol`, `Syntho-Ibuprofen`, `Egypto-Metformin`).
   - يتضمن كل عرض إخلاء مسؤولية قانوني وطبي بارز: *"بيانات دوائية تجريبية لأغراض المحاكاة والتطوير فقط"*.

2. **انعدام الأسرار والمفاتيح المشفرة (Zero Hardcoded Secrets)**:
   - الكود المصدري خالٍ تماماً من أية مفاتيح سرية، رموز وصول (Tokens)، أو كلمات مرور مشفرة.
   - تم توفير ملف `.env.example` كقالب استرشادي موثق، مع تجاهل ملفات البيئة الحساسة (`.env.local`) في `.gitignore`.

3. **حماية البيانات الصحية الحساسة وفقاً للقانون المصري (Law 151/2020)**:
   - تصنف الروشتات الطبية وبيانات الأمراض المزمنة وفقاً للمادتين (1) و(12) من قانون حماية البيانات الشخصية المصري كـ **"بيانات شخصية حساسة"**.
   - لا تتطلب المرحلة الأولى أية خوادم سحابية خارجية للتشغيل الأولي، مع تصميم بنية تخزين الروشتات السحابية المستقبلية بنظام الروابط المؤقتة المشفرة مسبقاً (Presigned URLs بمدة صلاحية 15 دقيقة فقط).

4. **الضوابط الصيدلانية المصرية (EDA Pharmacy Safeguards)**:
   - تفعيل حد أقصى للطلب بمقدار **5 علب لكل دواء** لمنع ظاهرة احتكار الأدوية وإعادة بيعها في السوق غير الرسمية.
   - وضع علامات تحذيرية صريحة على الأدوية التي تتطلب روشتة طبية (Rx Only) مع منع صرفها الآلي دون فحص صيدلاني مرخص.
